
**credit_card_fraud_detection**
**🚀 SQL-based Credit Card Fraud Detection using Kaggle dataset**

**📌 Project Overview**
This project focuses on **Credit Card Fraud Detection** using **SQL-based analysis**. We use the [Credit Card Fraud Detection dataset from Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud), which contains real anonymized transaction data.

**🔍 Goals of this project**:
✅ Identify fraud patterns in transaction data.
✅ Optimize SQL queries for faster fraud detection.
✅ Perform in-depth SQL analysis on fraudulent transactions.

*🛠️ Technologies Used*
* **SQL (MySQL Workbench)** – Data storage, queries, and fraud detection analysis.

**📊 Dataset Details**
- **Source**: Kaggle - Credit Card Fraud Detection
- **Columns:**
    - **`Time`**  Time elapsed from the first transaction.
    - **`V1 to V28`**  Anonymized transaction features.
    - **`Amount`**  Transaction amount.
    - **`Class`**  **0 (Normal)**, **1 (Fraudulent)**.

**🔍 SQL Analysis & Fraud Detection Queries**
**Key SQL Queries**:
✔️ Identifying **high-value fraud transactions**.
✔️ Detecting **frequent fraud patterns** in transactions.
✔️ Analyzing **peak fraud transaction times**.
✔️ **Optimizing SQL queries** for faster fraud detection.
